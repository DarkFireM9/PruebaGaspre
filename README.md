# PruebaGaspre

Solucion a la prueba tecnica de Gaspre de dominio jerarquico de categorias.

---

## Requisitos

- Node.js ≥ 18
- npm ≥ 9

## Instalación

```bash
npm install
```

## Ejecución de tests

```bash
npm test
# con coverage
npm run test:coverage
```
